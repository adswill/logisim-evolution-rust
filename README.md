# rcirc

A Rust rewrite of [Logisim Evolution](https://github.com/logisim-evolution/logisim-evolution), aiming to be friendlier to beginners. GPL-3.0-or-later.

Crates: `logisim-core` (signals, simulation), `logisim-components`, `logisim-format` (.rcirc, RON), `logisim-app` (egui desktop app).

    cargo run -p rcirc
